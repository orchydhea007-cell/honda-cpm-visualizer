CPM Formula
ES[v] = max(EF[u]) untuk semua predecessor u
EF[v] = ES[v] + duration[v]
LF[v] = min(LS[w]) untuk semua successor w
LS[v] = LF[v] − duration[v]
Float = LS[v] − ES[v] = LF[v] − EF[v]
Critical = Float == 0
Kahn's Algorithm
1. Hitung in-degree semua node
2. Queue: semua node in-degree = 0
3. Dequeue → tambah ke topo_order
4. Kurangi in-degree successor
5. Jika in-degree → 0, masuk queue
Valid jika len(order) == total nodes
